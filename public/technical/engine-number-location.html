Jaguar Engine Number Location - Where To Find It

A complete guide to locating the engine number on every Jaguar engine family. Covers VIN decoding, block stamp positions for Ingenium, AJ-V6, AJ-V8, AJ126, AJ133, 276DT, 306DT, and classic XK6/V12 engines. No opinions, no verdicts – just the facts, sourced from OEM workshop data.

The Jaguar engine number is stamped on the cylinder block and encoded in the VIN (position 8). The most common locations are front face behind the water pump (AJ126/AJ133), left-hand side below the exhaust manifold (Ingenium 2.0), and rear face adjacent to the bellhousing (V6 diesel).

  • VIN position 8 gives the engine code letter – cross-check with the block stamp [THIRD-PARTY - OEM VIN standard]
  • Block stamp format: 6–8 alphanumeric characters, often with a suffix indicating power variant
  • Common locations per family are detailed below – always verify with a mirror and torch

How to Decode the Engine Number from the VIN

In every Jaguar built since the late 1990s, the engine code is encoded in the 17‑character VIN. Position 8 is the engine code letter – this is the most reliable way to confirm the factory‑fitted engine without reading the block stamp.

VIN Position 8 – Mapping to Engine Codes

The following table shows the most common VIN position‑8 letters for Jaguar engines. Note that some letters are used across multiple engine families – always cross‑check with the engine code table.

  • A – 204DTD (2.0L Ingenium diesel)
  • D – 204PT (2.0L Ingenium petrol)
  • F – AJ126 (3.0L V6 supercharged)
  • G – AJ133 (5.0L V8 supercharged)
  • H – 306DT (3.0L V6 diesel)
  • J – AJ20D6 (3.0L I6 diesel)
  • K – 276DT (2.7L V6 diesel) – earlier models
  • L – AJ‑V8 4.2L supercharged
  • M – AJ‑V8 4.0L naturally aspirated

For older classics (XJ Series, E‑Type), the VIN may not encode the engine – the physical stamp is the only source. Use our VIN Decoder Tool for a full breakdown of your Jaguar’s specifications.

How to Verify the Engine Number on the Vehicle

The most reliable method is the VIN, as described above. If you need to visually confirm the engine number from the block, follow these steps:

  1. Prepare the area: Ensure the engine is cold (avoid burns) and the area is well‑lit. Use a torch and a small mirror.
  2. Locate the machined pad using the table in Section 1 – it will be a flat, unpainted surface.
  3. Clean the surface with a rag and, if necessary, a wire brush to remove dirt and corrosion.
  4. Read the stamp – the number is usually 6–8 characters. Write it down or take a photo.
  5. Cross‑check with the VIN – position 8 should match the engine code letter. If they differ, the engine may have been swapped.

For detailed location photos and diagrams, refer to the Engine Code Decoder guide, which includes visual references for each engine family.

Common Mistakes When Locating the Engine Number

  • Looking in the wrong place for the engine family. The location varies significantly – using the table above is essential.
  • Assuming the VIN code is the same as the block stamp. The VIN letter is an abbreviated code; the block stamp gives the full engine number including production sequence.
  • Misreading the stamp due to dirt or corrosion. Clean the pad thoroughly before attempting to read it.
  • Ignoring the suffix – suffixes like -S or -A indicate power variants or running changes, which matter when ordering replacement parts.
  • Not checking both sides of the block – on some engines (e.g., AJ126), the stamp is hidden behind the water pump; a mirror is essential.

Why the Engine Number Matters

The engine number is the definitive identifier for your Jaguar's engine. It is used for:

  • Ordering correct replacement parts – gaskets, timing components, and sensors often vary by engine variant.
  • Verifying engine swaps – if the block stamp and VIN code don't match, the engine may have been changed, affecting value and compatibility.
  • Checking for recalls – some recalls apply to specific engine serial number ranges (see our Recall Pages).
  • Insurance and legal documentation – the engine number is recorded on the V5C logbook in the UK.

Always record your engine number and keep it with your service records – it will save time and prevent costly mistakes when ordering parts or getting quotes from specialists.
