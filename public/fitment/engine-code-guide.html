How to Identify Your Engine from the VIN

The 8th character of your Jaguar VIN is your engine code — once you know what to look for, it takes seconds to confirm.

Your Jaguar's VIN (Vehicle Identification Number) is a 17-character code that encodes everything about your car, including the engine. The 8th character — sometimes called the "engine code digit" — maps directly to a specific engine type. For example, an 8th character of 5 often indicates a 3.0 V6 diesel, while 8 might indicate a 5.0 V8. However, the exact mapping varies by model and year, so we've built a dedicated VIN Decoder tool that handles the complexity for you.

Example: VIN SAJWA1EN8G8V12345 — the 8th character is 8, which may indicate a 5.0 V8. Always confirm with our decoder, as multiple codes can share the same digit across different model years.

Engine Number Location

Where to find the engine number stamp on the block.

🔍

V6 Petrol (AJ126)

Stamped on the cylinder block near the thermostat housing, visible from the top with the engine cover removed.

🔍

V6 Diesel (306DT / 276DT)

Located on the left-hand side of the block, below the exhaust manifold — often requires a torch and mirror to read.

🔍

4-Cyl Ingenium

Stamped on the front of the block, behind the alternator — visible from above on most models.

🔍

V8 (AJ133 / AJ-V8)

Found on the rear of the block, near the bellhousing — often requires a mirror and good lighting.

Common Misidentifications

The mistakes that cost Jaguar owners time, money and the wrong engine delivery.

  • Confusing 306DT with AJ20D6. Both are 3.0L diesels badged D300/D350, but they are entirely different engine families. One is a V6, the other is a straight-six — and they are not interchangeable. Our 306DT vs AJ20D6 comparison shows the full differences.
  • Misreading the VIN. The 8th character is the engine code, but Jaguar has used overlapping codes across decades. Always decode against the specific model year using our VIN decoder.
  • Assuming engine code = badge. "D300" and "P300" describe power output, not engine family. The same badge can appear on completely different engines across model years — the engine code itself is the only reliable identifier.
  • Ordering a petrol engine for a diesel car. This sounds obvious, but we see it in the data — especially on Ingenium models where the exterior presentation is nearly identical. Always confirm your engine code before ordering any replacement.

Frequently Asked Questions

How do I find my Jaguar engine code?

You have three options: (1) The 8th character of your VIN is the engine code digit — use our VIN decoder to map it. (2) The engine number is stamped on the block; location varies by engine type, with a full guide above. (3) Our free registration lookup tool pulls your engine code instantly from the DVLA database.

Is the engine code the same as the engine number?

No. The engine code identifies the type (e.g., AJ126, 306DT), while the engine number is a unique serial number for your specific unit. The code is what you need for ordering a replacement or confirming fitment — the serial number is for vehicle registration and provenance.

Can I use the engine code to buy a replacement engine?

Absolutely — the engine code is the minimum required specification. However, you should also confirm the year and any revision markers, as some engines have pre- and post-revision variants (e.g., AJ133 timing chain tensioner was revised in 2013). Our specialist network uses the engine code plus model year to source the exact matching unit.

Why does the same model have different engine codes?

Jaguar regularly updates engines within a model lifecycle — for example, the XF X260 started with the 306DT V6 diesel and later switched to the AJ20D6 straight-six. Both are D300-badged but are mechanically unrelated. Always use the engine code, not the badge, to identify your engine.

My engine code isn't in the list above — what does that mean?

We've covered the most common Jaguar engines. If your code isn't listed, it may be a rare or older unit — please contact us and we'll add it to our reference database. Alternatively, check our full fitment matrix, which includes all Jaguar engines from the 1990s onward.
