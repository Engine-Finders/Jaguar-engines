Land Rover Restricted Performance Warning

JLR's own wording for what most manufacturers call limp mode. It isn't a fault in itself — it's the vehicle telling you it has detected one and has deliberately reduced power to protect something. Here's how to find out what.

Restricted Performance means your Land Rover's ECU has logged a fault and cut power to protect the engine or emissions system. The message itself tells you nothing about the cause — you need the stored fault code to know what you're dealing with.

  • Most common causes: DPF regeneration issues, boost/turbo faults, and fuel pressure problems [PATTERN DATA]
  • Usually accompanied by the engine management light and a stored code such as P0087, P0299 or P2463
  • Costs range from £90 (fuel filter) to £5,800 (timing chain) depending entirely on the underlying cause
  • Safe to drive short distances at reduced speed — not safe for motorway use, because you cannot accelerate normally

Read the code first. Everything below assumes you have one, or are about to get one.

What the Message Means

Restricted Performance is a protective state, not a diagnosis. When the ECU detects a reading outside its safe operating window — boost pressure, fuel rail pressure, exhaust backpressure, coolant temperature — it deliberately limits power output to prevent that condition causing damage. That is genuinely a good thing: the vehicle is protecting an expensive component. What it doesn't do is tell you which reading triggered it, which is why the stored fault code matters far more than the dashboard message. Two vehicles showing identical Restricted Performance messages can be facing a £90 filter and a £5,800 timing chain respectively.

What To Do In the Next 24 Hours

1

Note what you were doing

Did it appear under hard acceleration, on a motorway run, or in stop-start traffic? Urban-only driving points toward DPF; hard acceleration points toward boost or fuel pressure.

2

Check oil and coolant levels

A safe, driveway-level check. Low coolant alongside this message raises the priority considerably — see coolant loss with no visible leak.

3

Get the fault code read

The message is meaningless without it. Most independents and factors will read codes cheaply or free.

4

Don't just clear it

Clearing the code destroys the freeze-frame data a specialist would use to diagnose it, and it will return.

5

Try a sustained motorway run — only if DPF is suspected

If the code points to DPF soot accumulation and there are no other warnings, a 30–40 minute sustained run at motorway speed may allow a regeneration cycle to complete.

Cost to Diagnose and Fix

Diagnosis itself is typically one to two hours of specialist time. Can You Drive With Restricted Performance?

Short local journeys at reduced speed: yes. Motorway driving: no. The reason is straightforward — in this state the vehicle will not deliver full power on demand, which makes merging, overtaking and hill starts genuinely unsafe. Locally, at moderate speeds, driving it to a garage is reasonable. The exception is if Restricted Performance appears alongside an oil pressure warning, a coolant temperature warning, or any knocking noise — see our engine knocking noise guide — in those cases stop and recover the vehicle rather than driving it.

Frequently Asked Questions

What does Restricted Performance mean on a Land Rover?

It means the ECU has detected a fault and deliberately reduced engine power to protect a component — typically the turbo, DPF, or fuel system. It is a protective response rather than a fault in itself, and the stored fault code is what identifies the actual problem.

Can I reset Restricted Performance myself?

Clearing the code will remove the message temporarily, but it will return once the ECU detects the same condition again — usually within a drive cycle or two. Clearing it also erases the freeze-frame data a specialist would use to diagnose the cause, so it generally makes the repair harder rather than easier.

Will a motorway run fix Restricted Performance?

Only if the underlying cause is incomplete DPF regeneration, which is common on urban-driven diesels. A sustained 30–40 minute run at motorway speed can allow a regeneration cycle to complete. If the cause is anything else — boost, fuel pressure, EGR, timing — a motorway run will not help and may make matters worse.

Is Restricted Performance expensive to fix?

It varies more than almost any other warning on the vehicle. The same message can indicate a fuel filter under £180 or a timing chain approaching £5,800. That is why reading the code before accepting any quote matters so much.
